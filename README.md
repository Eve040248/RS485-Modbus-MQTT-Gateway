# RS485-Modbus-MQTT-Gateway
อุปกรณ์อุตสาหกรรมและมิเตอร์ไฟฟ้าส่วนใหญ่ใช้การสื่อสารแบบ RS485 ซึ่งไม่สามารถต่ออินเทอร์เน็ตได้โดยตรง ทำให้ยากต่อการนำข้อมูลเข้าสู่ระบบ IoT โครงงานนี้จึงสร้างเกตเวย์เพื่อทำหน้าที่เป็นตัวกลางอ่านค่าจากอุปกรณ์ RS485 และส่งข้อมูลขึ้นระบบ IoT
